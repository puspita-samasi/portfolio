# Puspita Samasi · Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript: no build step, no dependencies.

## Files
- `index.html`: page content
- `styles.css`: all styles (light and dark themes)
- `script.js`: dot background, rules-engine demo, skill filters, theme toggle
- `assets/`: photo and favicon
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy
Push to GitHub, then Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`.
